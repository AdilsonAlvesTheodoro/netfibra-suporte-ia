# NetFibra · Suporte com IA
===

# 

# Projeto desenvolvido em Streamlit para simular um assistente de suporte técnico com IA, usando LangGraph, histórico de conversa e integração com modelo via OpenRouter.

# 

# \## Objetivo

# 

# O objetivo do projeto é demonstrar como criar uma aplicação de atendimento com IA aplicada, mantendo contexto da conversa e exibindo uma trilha de execução do fluxo do agente.

# 

# \## Tecnologias utilizadas

# 

# \- Python

# \- Streamlit

# \- LangGraph

# \- OpenRouter

# \- dotenv

# \- streamlit-agraph

# 

# \## Funcionalidades

# 

# \- Chat interativo com assistente de IA

# \- Histórico de conversa durante a sessão

# \- Integração com modelo LLM via OpenRouter

# \- Visualização da trilha de execução do agente

# \- Estrutura preparada para fluxos com human-in-the-loop

#
